# Данные и признаки первого корпуса

Приоритет: текст ТЗ и последующие уточнения пользователя выше формул в Excel.
Исходная таблица прочитана целиком, без изменения файла.

| Поле из таблицы | Реализация / необходимые данные |
|---|---|
| doc_id | ID OpenAlex без URL; уникальный ключ, не признак модели |
| source_tier | preprint/patent из типа работы, journal/conference из типа источника; прочее — other, без выдуманной классификации |
| novelty_raw | Следующий этап: embeddings абстрактов и центроид домена только по документам, доступным к cutoff. Косинусное расстояние обычно [0,2], а не [0,1]; нормировку нужно явно выбрать |
| cluster_density | Следующий этап: среднее расстояние до 5 соседей, self исключён, индекс только на прошлом. Это расстояние, не обратная ему плотность |
| is_outlier_cluster | Следующий этап: HDBSCAN на данных до cutoff; -1 преобразуется в 1. Нельзя обучать кластеризацию сразу на всех годах |
| ppmi_domain_score | Следующий этап: обогащение доменов ссылок, таблица совместных появлений до cutoff. Не вычисляется из одних ID ссылок |
| commercial_maturity_index | Доля authorships с institution.type=company, если аффилиации известны для всех авторов. При неполных аффилиациях None; отдельно affiliation_coverage. Упоминания компаний в тексте пока не классифицируются |
| citation_velocity | Нужны цитирования к cutoff и явно выбранный возраст/момент наблюдения. Текущий cited_by_count запрещён в исторических X |
| citation_acceleration | Нужны исторические годовые количества; формула в Excel повреждена. Рабочую формулу следует задавать явно; годовые бины не дают точных скользящих 12/24 месяцев |
| distinct_venues_ratio | Нужны источники входящих цитирующих работ до cutoff, а не bibliography исходной статьи |
| author_growth_rate | Требуется первая наблюдаемая публикация каждого автора в теме. Сохраняется кэш первых лет авторов для тем с кандидатами Y=1 |
| has_ref_data | 1 означает непустой доступный список references, НЕ доказанную полноту библиографии |
| target_emergence | >=4 по публикациям И >=2.5 по новым авторам; обучающие годы 2010–2020, остальные None |

## Historical Target

Единица темы — стабильный `primary_topic_id`, а не изменяемое название. Популяция Y — все работы,
для которых эта тема основная, без фильтра по абстракту и references. Это отличается от популяции
выборки X, на которую наложены фильтры качества. Агрегаты не оцениваются по выборке 1 млн.

Для каждого t сравниваются суммы публикаций за [t-2,t] и [t+3,t+5], epsilon=1e-8.
Если рост публикаций <4, Y=0 независимо от авторов. В остальных случаях минимальная выгрузка
id/year/authorships охватывает ВСЮ доступную историю темы до 2025 включительно.
Новый автор — автор, чья первая известная публикация в данной основной теме попала в окно.
Если авторский baseline нулевой, Y остаётся None с причиной insufficient_author_baseline.
Недостающие авторские ID и ошибки дизамбигуации OpenAlex ограничивают точность метрики.
Это может потребовать существенного числа дополнительных запросов и нескольких дней.

## Исторические цитирования

`citations_at_cutoff` оставлено по имени из ТЗ, но содержит текущий `cited_by_count` на `fetched_at`.
Это сырые метаданные, не исторический признак. `counts_by_year` сохраняется как JSON, без
восстановления несуществующих значений. OpenAlex предоставляет примерно последние 10 лет.
Функция `historical_citations` запрашивает /works?filter=cites:W...,publication_year:...&group_by=publication_year
и кэширует полные доступные годовые бины входящих работ. Это дорого при вызове на 1 млн работ,
поэтому массовое обогащение отдельно от сбора корпуса.

Даже такой расчёт реконструирует прошлое по сегодняшнему графу. Даты добавления записей,
исправленные ссылки и современная классификация тем не воспроизводят настоящий снимок 2015 года.
Для строгого point-in-time эксперимента нужны исторические снимки или отдельные ограничения доступности.

## Статус

Сборщик готовит сырые метаданные и часть непосредственно вычислимых полей. Embeddings,
HDBSCAN, PPMI и полный набор исторических X ещё не реализованы. Их значения не подменяются
нулями или случайными числами. Подготовка корпуса не означает готовность матрицы CatBoost.
