# Временное разделение нового корпуса

Новый сборщик находится в `new_dataset/`. Его текущие объём, годы и путь выгрузки задаются `new_dataset/config_new.json`; сейчас это **1 000 000** работ за 2017–2026 годы. Запуск и структура папки — в [`RUN_NEW_DATASET.md`](RUN_NEW_DATASET.md).

| Годы | Роль при подготовке модели |
|---|---|
| 2017–2019 | История для расчёта прошлых признаков, не обучающая выборка |
| 2020–2021 | Train |
| 2022 | Validation |
| 2023 | Test |
| 2024–2026 | Будущие годы для расчёта исторической метки, не вход модели |

`new_dataset/pipeline/` собирает и размечает строки по этим группам, но не обучает модель и не создаёт метку слабого сигнала. `preprocessing/create_features.py` рассчитывает признаки и `target_emergence`, используя прошлое окно `t−3..t−1` и будущее окно `t+1..t+3` только для метки. Поэтому поддерживающие годы нужны при расчёте, но не должны попадать в train/valid/test как обучаемые строки.

Итог сбора по текущей конфигурации: `new_dataset/new_data/openalex_corpus_1m.parquet`. Итог расчёта признаков: `new_dataset/new_data/final_openalex_dataset.parquet`. Для строгой проверки на новых годах нельзя смешивать будущие признаки с входом модели.
