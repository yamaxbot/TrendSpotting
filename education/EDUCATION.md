# Baseline-модель для определения слабых сигналов

> Исторический baseline; это не метрики модели, используемой сайтом. Актуальные эксперименты: [README.md](README.md) и [../outputs/README.md](../outputs/README.md).

## Цель

В качестве первого baseline была построена модель бинарной классификации на основе **CatBoostClassifier**.

Задача модели — по рассчитанным признакам научной публикации определить, относится ли объект к потенциальному слабому сигналу.

Целевая переменная:

- `target_emergence = 1` — emerging / потенциальный слабый сигнал;
- `target_emergence = 0` — не emerging.

---

## Данные

Для обучения используется подготовленный датасет с рассчитанными признаками публикаций.

После удаления объектов без значения `target_emergence` в датасете осталось **588 236 объектов**.

Распределение классов:

| Класс | Количество | Доля |
|---|---:|---:|
| `0` | 545 598 | 92.75% |
| `1` | 42 638 | 7.25% |

Таким образом, выборка является сильно несбалансированной: положительный класс составляет около **7.25%** объектов.

---

## Используемые признаки

В baseline используются следующие признаки:

- `source_tier` — уровень/тип источника;
- `novelty_raw` — оценка новизны публикации;
- `cluster_density` — плотность кластера похожих исследований;
- `is_outlier_cluster` — принадлежность к кластеру-выбросу;
- `ppmi_domain_score` — оценка необычности связи между научными областями;
- `commercial_maturity_index` — индекс коммерческой зрелости;
- `citation_velocity` — скорость набора цитирований;
- `citation_acceleration` — ускорение набора цитирований;
- `distinct_venues_ratio` — распределение активности между различными площадками;
- `author_growth_rate` — темп роста числа авторов в направлении;
- `has_ref_data` — наличие необходимых библиографических данных.

`doc_id` используется только как идентификатор объекта и не передаётся модели.

`target_emergence` является целевой переменной и также не входит в признаки.

---

## Обучение модели

В качестве baseline используется **CatBoostClassifier**.

CatBoost подходит для задачи с табличными признаками, умеет напрямую работать с категориальными признаками и поддерживает пропущенные значения в числовых признаках.

`source_tier` передаётся модели как категориальный признак.

Из-за сильного дисбаланса классов при обучении использовалась балансировка классов, чтобы модель уделяла больше внимания редкому классу `1`.

Обучение проводилось до **3000 итераций**.

Лучший результат на validation-выборке был получен на итерации:

```text
bestIteration = 2992
bestTest = 0.9128941216
```

После обучения CatBoost сократил итоговую модель до первых **2993 деревьев**:

```text
Shrink model to first 2993 iterations.
```

## Результаты классификации

На тестовой выборке размером **117 648 объектов** получены следующие результаты:

| Класс | Precision | Recall | F1-score | Support |
|---|---:|---:|---:|---:|
| `0` | 0.99 | 0.93 | 0.96 | 109 120 |
| `1` | 0.49 | 0.90 | 0.64 | 8 528 |
| **Accuracy** |  |  | **0.93** | 117 648 |
| **Macro avg** | 0.74 | 0.91 | 0.80 | 117 648 |
| **Weighted avg** | 0.96 | 0.93 | 0.93 | 117 648 |

Для целевого класса `1`:

- **Precision = 0.49** — среди объектов, которые модель определила как слабые сигналы, около 49% действительно относятся к классу `1`;
- **Recall = 0.90** — модель обнаруживает около 90% всех настоящих объектов класса `1`;
- **F1 = 0.64** — баланс между Precision и Recall.

Также получено:

```text
ROC-AUC = 0.9720270903153937
```

Высокий ROC-AUC показывает, что модель хорошо разделяет положительные и отрицательные объекты по своему score.

Из-за сильного дисбаланса классов Accuracy не рассматривается как основная метрика. Основное внимание уделяется **Precision, Recall и F1 для класса `1`**.

## Анализ Classification Threshold

После обучения отдельно исследовалось влияние порога классификации на Precision и Recall положительного класса.

Получены следующие результаты:

| Threshold | Precision | Recall | F1 |
|---:|---:|---:|---:|
| 0.85 | 0.828050 | 0.505394 | **0.627685** |
| 0.90 | 0.890578 | 0.377932 | 0.530666 |
| 0.92 | 0.910605 | 0.314142 | 0.467132 |
| 0.95 | 0.948929 | 0.202627 | 0.333945 |
| 0.978798 | 0.981873 | 0.076220 | 0.141458 |

При увеличении threshold модель становится более строгой при присвоении класса `1`.

Это приводит к увеличению **Precision**, но одновременно уменьшает **Recall**.

Например, при:

```text
threshold = 0.978798
```

получаем:

```text
Precision = 0.981873
Recall = 0.076220
F1 = 0.141458
```

То есть почти **98.2% объектов**, которым модель присвоила класс `1`, действительно являются положительными, однако при этом модель обнаруживает только около **7.6% всех положительных объектов**.

Среди рассмотренных порогов наибольший F1 получен при:

```text
Threshold = 0.85
Precision = 0.828050
Recall = 0.505394
F1 = 0.627685
```

Это лучший F1 **среди приведённых порогов**. Для окончательного выбора threshold его необходимо подбирать на validation-выборке, а затем фиксировать и проверять на test-выборке.

## SHAP-анализ

Для интерпретации модели был рассчитан **SHAP importance** — средний абсолютный вклад каждого признака в предсказания CatBoost.

Получены следующие значения:

| Признак | SHAP importance |
|---|---:|
| `author_growth_rate` | **0.864185** |
| `cluster_density` | **0.860812** |
| `ppmi_domain_score` | 0.207344 |
| `citation_acceleration` | 0.173421 |
| `citation_velocity` | 0.150221 |
| `novelty_raw` | 0.121748 |
| `source_tier` | 0.110458 |
| `commercial_maturity_index` | 0.053163 |
| `is_outlier_cluster` | 0.028934 |
| `distinct_venues_ratio` | 0.024824 |
| `has_ref_data` | 0.000000 |

Наибольшее влияние на решения модели оказывают:

1. `author_growth_rate`;
2. `cluster_density`.

Их SHAP importance значительно выше остальных признаков.

Следующими по значимости являются:

- `ppmi_domain_score`;
- `citation_acceleration`;
- `citation_velocity`;
- `novelty_raw`.

`has_ref_data` имеет SHAP importance `0.0`, то есть в текущей модели этот признак фактически не влияет на предсказания.

SHAP-анализ позволяет понять, на каких признаках основывается модель, а также может использоваться для поиска подозрительных признаков и возможного **data leakage**.

## Итог baseline

Текущая baseline-модель построена на **CatBoost** и рассчитанных табличных признаках научных публикаций.

Основные результаты:

| Метрика | Значение |
|---|---:|
| ROC-AUC | **0.9720** |
| Recall класса `1` | **0.90** |
| Precision класса `1` | **0.49** |
| F1 класса `1` | **0.64** |
| Accuracy | **0.93** |
| Macro F1 | **0.80** |
| Weighted F1 | **0.93** |

Модель обладает высоким Recall и обнаруживает большую часть объектов класса `1`.

При стандартной классификации основной недостаток модели — сравнительно невысокий Precision (`0.49`), то есть среди предсказанных слабых сигналов присутствует значительное количество False Positive.

Изменением classification threshold можно управлять балансом между Precision и Recall. Например, при threshold `0.85` Precision увеличивается до **0.828**, однако Recall уменьшается до **0.505**.

SHAP-анализ показал, что наиболее важными для модели являются `author_growth_rate` и `cluster_density`.

## Дальнейшие шаги

1. Зафиксировать корректное разделение на `train / validation / test`.
2. Подбирать classification threshold только на validation-выборке.
3. Проверить наиболее важные признаки на возможный data leakage.
4. Проанализировать `author_growth_rate` и `cluster_density`, поскольку их влияние значительно выше остальных признаков.
5. Сравнить различные варианты балансировки классов.
6. При необходимости добавить текстовые признаки из `title` и `abstract`.
7. Провести temporal backtesting, при котором признаки рассчитываются только из информации, доступной на выбранную историческую дату.
