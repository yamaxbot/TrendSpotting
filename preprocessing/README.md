# `preprocessing/` — признаки и метка

`create_features.py::build_real_features(input_path, output_path)` преобразует корпус OpenAlex в таблицу для CatBoost. Он считает признаки динамики темы/авторов, текстовой новизны, научных связей, площадок и цитирования. Историческая метка `target_emergence` строится по будущему развитию темы для датасетов обучения; при поиске на сайте целевую метку в прогноз не передают.

При запросе сайта вход — `website/data/parse_corpus_*.parquet`, выход — `website/data/build_dataset/dataset_*.parquet`. В офлайн-эксперименте значения путей по умолчанию в скрипте указывают на `download_dataset/new_dataset/new_data/`. Некоторые признаки оцениваются в пределах доступного корпуса; сравнение разных корпусов требует осторожности.

`create_features_randomsplit.py` — отдельный эксперимент с построением исторического состояния для случайного/временного разбиения; сайт его не вызывает. `dataset_check.py` — исследовательская проверка распределений и связей признаков. [`preprocessing.md`](preprocessing.md) фиксирует ранний baseline и не описывает весь текущий набор признаков.
