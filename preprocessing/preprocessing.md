# Расчёт признаков

Эта папка превращает корпус статей в таблицу признаков и меток для обучения либо в признаки текущего запроса сайта.

## Структура

| Файл | Роль |
|---|---|
| `create_features.py` | Основной расчёт динамики темы/авторов, текстовых и графовых, издательских, ссылочных и цитатных признаков; экспорт Parquet |
| `create_features_randomsplit.py` | Вариант подготовки для эксперимента со случайным разбиением |
| `dataset_check.py` | Проверка распределений и качества готового датасета |

Для офлайн-обучения `create_features.py` по умолчанию читает `download_dataset/new_dataset/new_data/openalex_corpus_1m.parquet` и пишет `final_openalex_dataset.parquet` рядом. Его `build_real_features(input_path, output_path)` также вызывается сайтом для корпуса, собранного под запрос. Признаки учитывают научное окружение статьи, поэтому один абстракт не заменяет входную таблицу модели. Историческая метка `target_emergence` нужна для обучения и не является известным фактом о новых статьях.

Запуск офлайн из корня проекта: `python preprocessing/create_features.py`. Для сайта отдельный запуск не нужен.
