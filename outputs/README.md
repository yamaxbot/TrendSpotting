# `outputs/` — результаты экспериментов

Это сохранённые модели и отчёты, а не входные данные для парсера. Источник истины для рабочего сайта — `catboost_splits/random/catboost_model.cbm` и соседний `metrics.json` (порог классификации). `website/main.py` загружает их по фиксированным путям.

| Каталог | Эксперимент | Тестовые показатели из сохранённых отчётов |
|---|---|---|
| `catboost_splits/random/` | 24 признака, случайное разбиение | ROC-AUC 0,945; PR-AUC 0,780; F1 0,683 |
| `catboost_splits/temporal/` | Те же 24 признака, train 2020–2021 / validation 2022 / test 2023 | ROC-AUC 0,609; PR-AUC 0,121; F1 0,214 |
| `catboost/` | Бинарная модель с временным разделением, 23 признака | ROC-AUC 0,626; PR-AUC 0,128; F1 0,237 |
| `catboost/regression/` | Регрессионный вариант из `education/test/experiments.py` | Сохранены модель, пороги и матрицы ошибок; отдельного `metrics.json` нет |
| `catboost/ranking/` | Попарное ранжирование по группам годов | Test PR-AUC 0,253; Precision@100 0,475 по отчёту эксперимента |

`catboost_splits/comparison.json` сравнивает random/temporal; CSV и PNG в подкаталогах — пороги, важность признаков, SHAP и матрицы ошибок. Хороший результат на случайном разбиении не переносится автоматически на новые годы — временной тест это показывает. Не заменяйте рабочую модель файлом другого эксперимента без согласования списка признаков и повторной проверки сайта.
