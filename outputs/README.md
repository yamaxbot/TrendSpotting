# Сохранённые модели и результаты

Здесь лежат артефакты офлайн-обучения; новые модели при обычном поиске не обучаются.

| Путь | Что содержит |
|---|---|
| `catboost_splits/random/` | Рабочая модель сайта `catboost_model.cbm`, порог в `metrics.json`, отчёты по случайному разделению |
| `catboost_splits/temporal/` | Аналогичная проверка с разделением по годам |
| `catboost_splits/comparison.json` | Сравнение random/temporal |
| `catboost/` | Отдельная временная модель и метрики |
| `catboost/ranking/`, `catboost/regression/` | Эксперименты с ранжированием и регрессией |

В подкаталогах также находятся CSV/PNG важности признаков, матриц ошибок и порогов. `website/main.py` использует **только** `catboost_splits/random/catboost_model.cbm` и соседний `metrics.json`; замена модели требует совместимого набора признаков и проверки сайта. По сохранённым отчётам ROC-AUC random ≈ 0,945, temporal ≈ 0,609: метрики случайного разбиения нельзя считать оценкой качества на новых годах.
