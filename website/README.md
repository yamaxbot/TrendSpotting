# `website/` — веб-сервис

`manage.py` запускает Django. `trendspotting/` содержит настройки, URL и WSGI; `trends/` — страницы, фоновые задания, график и поиск подтверждающих публикаций; `templates/` и `static/` — интерфейс. `website/data/` — локальные результаты и кэш, не исходный код.

`main.py` связывает парсер, `preprocessing/create_features.py` и модель `outputs/catboost_splits/random/`. После оценки статьи `article_type.py` исключает обзоры, `relevance_gate.py` проверяет прямое соответствие запросу, `diversity.py` убирает близкие дубли. `query_llm.py` переводит заголовки и формирует текст по аннотации; если фактов не хватает, вывод ограничивается доступными данными.

`trends/jobs.py` выполняет поиск в фоновой очереди одного процесса. `trends/evidence.py` ищет похожие работы и кэширует ссылки; `trends/statistics.py` отдельно строит более широкий годовой ряд, `charts.py` готовит значения графика, `organizations.py` извлекает организации из метаданных авторов. Результаты и статус возвращают `views.py` и `urls.py`.

`templates/base.html` задаёт каркас; `templates/trends/` содержит поиск, детали и две информационные страницы. `static/css/` — стили, `static/js/site.js` — опрос статуса фоновых задач. `trendspotting/settings.py` читает настройки из окружения, а `wsgi.py` служит точкой входа Gunicorn.

Проверка: `python website/manage.py test trends --noinput`. Локальный запуск: `python website/manage.py runserver`. Для контейнера и переменных окружения см. [главный README](../README.md). Очередь и её статусы теряются при перезапуске процесса; масштабирование несколькими воркерами сейчас не поддерживается.

[`website.md`](website.md) — описание раннего статического прототипа, не схема текущего поиска.
