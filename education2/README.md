# Дополнительные эксперименты

Локальная папка для проверки новых моделей и сопоставления со списком 100 слабых сигналов. Она исключена из Git и Docker-образа; работа сайта от неё не зависит.

| Путь | Роль |
|---|---|
| `final_openalex_dataset.parquet` | Подготовленная офлайн-таблица признаков |
| `train_model*.ipynb`, `temporal_search.py`, `temporal_lightgbm_search.py`, `temporal_final_check.py` | Обучение и поиск вариантов временной модели |
| `catboost*.cbm`, `temporal_*results.json`, `temporal_final_check.json` | Локальные модели и отчёты |
| `benchmark.py` | Проверка сохранённой модели |
| `100_слабых_технологических_сигналов_сентябрь_2026.xlsx`, `build_signal_test_candidates.py`, `signal_test_candidates/` | Сопоставление ссылок из таблицы с OpenAlex и подготовка кандидатов для ручной проверки |
| `test_build_signal_test_candidates.py` | Тесты сопоставления |

Результаты этой папки не подменяют рабочую модель сайта автоматически. Перед заменой нужны совместимые признаки, независимый тест и обновление пути модели в `website/main.py`.
